# Browser compatibility matrix

Generated by `studio/scripts/compat_matrix.py` from the tool catalog; one row per entry in [`matrix.csv`](matrix.csv). `--check` keeps it current (studio/runner/tests).

Entries: 651. Running in the browser today (classes 1, 1g, 1j, 2, 3, 5): 638; as browser jobs (1j): 7; with a local kernel (2, 3): 7; on the local runner only (6, 7, 8): 13.

Routing coverage is not input coverage (the `browser_scope` column): of the 638 entries the browser runs, it runs 634 for every argument and 4 for some arguments only (job.pipeline.admet, job.pipeline.dock, job.pipeline.rnaseq, job.pipeline.scrna): there the arguments the entry's `execution.browser_job.runner_only` rules name take a call to the runner, with the reason. 13 entries run on the runner only. A class says where an entry runs, not that its browser output was compared with native CPython.

Validation (the `validation` column) is each entry's committed verification record (`entry.verification` in the catalog): 526 entries have one, 125 are UNVERIFIED (no record, which is not a failure).
